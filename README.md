# Дан сайт и уникальный токен. Нужно получить свой секрет, следуя указаниям на страницах.

## Предлагается реализовать следующие подходы к решению (один или несколько):
* **[8 балла]** с использованием библиотек для работы с HTTP
* **[10 баллов]** с использованием утилит `wget`/`curl`
* **[12 баллов]** с ручным формированием и разбором HTTP-пакетов

## Результатом решения с использованием подход должна быть отдельная программа, выполняющая получение секретного токена и выводящая его на консоль.

## Программы должны быть написаны на одном из языков: bash, python, C, js, C#, . Допускается использование разных языков для разных подходов к решению.
